1/*
2 * brix_fault_lever.h — the per-direction fault-lever record shared between the
3 * brix-fault-proxy core (brix_fault_proxy.c) and the optional named-toxic module
4 * (brix_fault_toxic.c).
5 *
6 * The core owns the two live instances (`g_up` / `g_down`) and every field's
7 * semantics; the toxic module only ever *composes* a stack of named toxics into
8 * a caller-owned snapshot copy (never the live levers), so the type — not the
9 * state — is what crosses the boundary. Kept header-only and dependency-free so
10 * both translation units agree on the layout with no other coupling.
11 */
