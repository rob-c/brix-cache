4/*
5 * cms_admin.h — §2.x CMS runtime admin unix socket (`brix_cms_admin_socket`).
6 *
7 * WHAT: the cluster-plane sibling of §1.16's session admin socket. Same
8 * transport (src/net/admin/admin_unix.c), same security model, a
9 * different verb table — one that operates on the SHM node registry
10 * rather than on this worker's live sessions:
11 * nodes -> ok <n>\n then one line per node:
12 * "<host>:<port> role=<r> free_mb=<n> util_pct=<n> state=<s>"
13 * (field names match brix_srv_snapshot_entry_t, so the wire and
14 * the struct cannot drift; state is up|drained|space-blocked)
15 * drain <host> <port> [<secs>] -> ok (default 300s, as the
16 * HTTP admin API's drain)
17 * undrain <host> <port> -> ok | err not-found
18 * forget <host> <port> -> ok (unregister)
19 * reset <host> <port> -> ok | err not-found
20 *
21 * WHY: stock exposes cluster state and node control through the cmsd admin
22 * interface. Everything needed already exists here — the registry
23 * helpers (`brix_srv_snapshot`, `brix_srv_blacklist`, `brix_srv_undrain`,
24 * `brix_srv_unregister`, `brix_srv_reset`) back the HTTP admin API in
25 * `src/observability/dashboard/api_admin_cluster.c`. What was missing was
26 * a way to reach them WITHOUT the HTTP dashboard: a manager that runs no
27 * dashboard, or an operator on the box during an incident when the HTTP
28 * plane is exactly what is unwell, had no cluster control at all.
29 *
30 * HOW: the verbs call the same registry helpers the HTTP handlers call, with
31 * the same defaults and the same not-found semantics, so the two surfaces
32 * cannot drift into disagreeing about what "undrain" means. The registry
33 * is in SHM, so unlike the session socket this plane is NODE-wide: any
34 * worker's socket sees and controls every node, and an operator needs
35 * only one of them.
36 *
37 * SECURITY: chmod 0600, no in-band auth — filesystem permission on the path IS
38 * the privilege boundary (see admin_unix.h). Every mutating verb emits a
39 * structured NGX_LOG_NOTICE audit line naming action, target and result,
40 * matching api_admin_cluster.c's fields.
41 *
42 * DIVERGENCE, deliberate: those lines are NOT hash-chained, while the
43 * HTTP admin API's are (api_admin.c admin_audit(), P90-28.2). The chain
44 * makes a NETWORK-REACHABLE API tamper-evident — it defends against
45 * someone who can reach the endpoint but not the log. This socket is
46 * reachable only by a principal who can already open a 0600 path on the
47 * box, and such a principal can rewrite the log itself; a chain would
48 * assert an integrity property the threat model does not support. The
49 * fields are identical so the two streams can be read together.
50 */
