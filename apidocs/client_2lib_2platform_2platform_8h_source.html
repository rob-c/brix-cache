2 * client/lib/platform/platform.h - the native client's platform umbrella
3 *
4 * WHAT: The one header client code includes for anything host-specific. It
5 * re-exports the module PAL (platform/platform_api.h, reached through
6 * -I$(SRC)) and adds the client's own entry points and the readiness-set
7 * API the client loop is written against (epoll(7); Darwin emulates it
8 * over kqueue). No host conditional lives here: the host part comes from
9 * client/lib/platform/<host>/host.h through the same computed include
10 * the module PAL uses.
11 * WHY: tools/ci/check_platform_leak.py rejects OS macros and OS-private
12 * headers outside the host directories; client/lib/platform/<host>/ is
13 * the client's owner.
14 */

45/**
46 * Two-phase idle expiry of a mount (Linux umount2(MNT_EXPIRE), root only):
47 * 0 = unmounted now, -1/EAGAIN = marked and left for the next call,
48 * -1/EBUSY = in use, -1/EPERM = not permitted. Darwin has no expiry and
49 * always answers EPERM, so callers disable the feature the same way an
50 * unprivileged Linux run does.

57/**
58 * The tier-th (0 first) command an unprivileged process runs to unmount a
59 * FUSE filesystem at `path`, most specific first: Linux fusermount3 -u [-z],
60 * fusermount -u [-z], umount [-l]; Darwin umount [-f] (the owner may unmount
61 * its own mount and there is no lazy detach, -f is the retry). Fills a
62 * NULL-terminated argv of at most BRIX_PLAT_UMOUNT_ARGV_MAX entries whose
63 * strings are static literals plus `path`.
64 * @return the argv length, or 0 when there is no such tier
65 */

79/**
