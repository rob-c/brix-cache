20/*
21 * Legacy xattr naming scheme: an xattr key is
22 * "user.nginx_xrootd.webdav." <hex(namespace-URI)> "." <hex(local-name)>
23 * Both the XML namespace URI and the local element name are lowercase-hex
24 * encoded so that arbitrary URI bytes (':', '/', '.', etc.) survive the
25 * "user." flat keyspace, and the single literal '.' separator is unambiguous
26 * (real dots inside the URI/name become "2e", never a bare '.').
27 * When that spelling exceeds the selected host's xattr-name limit, the payload
28 * is written as "~" + base64url(namespace) + "." + base64url(local-name).
29 * The marker cannot occur in legacy hex, so both formats remain readable.
30 * NAME_MAX is the largest supported host budget; VALUE_MAX/LIST_MAX cap how
31 * much we will read back so a hostile filesystem cannot force unbounded allocs.
32 */
