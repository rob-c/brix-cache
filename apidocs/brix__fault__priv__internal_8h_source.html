1/* brix_fault_priv_internal.h — seam between the privileged-lever TUs.
2 *
3 * WHAT: The subprocess runners and operator-argument validators defined in
4 * brix_fault_priv_exec.c, the netem plane defined in
5 * brix_fault_priv_netem.c, and the lever state owned by
6 * brix_fault_priv.c — everything the three TUs share.
7 *
8 * WHY: The three TUs are one unit split for the 600-line cap
9 * (coding-standards §1). Nothing outside brix-fault-proxy includes this;
10 * the public lever API stays in brix_fault_priv.h.
11 *
12 * HOW: Validators return 1 = accept, 0 = reject, and never mutate the input.
13 * Runners return the child's exit status, or -1 if it could not start.
14 * Every netem entry point below expects the caller to hold g_lock, which
15 * brix_fault_priv.c takes at the public API boundary. */
