4/*
5 * sd_frm_lib_abi.h — the library-native HSM adapter ABI (phase-64).
6 *
7 * WHAT: the C entry points a shared object must export to serve as a
8 * library-native MSS back end for the "lib" / "libhpss" / "libcta" FRM
9 * dialects. The sd_frm "lib" adapter dlopen()s the .so and dlsym()s these
10 * symbols; each verb is an in-process function call, NOT a fork+exec of a
11 * stage command. That is the whole point of this adapter: on a busy silo
12 * the exec transport forks a `hsi`/`eos` helper per recall/residency probe,
13 * and the per-verb fork+exec+wait dominates the latency of small-object
14 * staging — a native library call removes it.
15 * WHY: a header both the real vendor shim and the test mock include, so the
16 * symbol names and signatures cannot drift between producer and consumer.
17 * HOW: the online buffer is still a local directory the adapter manages
18 * (open/create/pread live in the adapter); the library only owns the
19 * tape<->online-buffer transfer and residency. Recall is expected to
20 * BLOCK until the object is in `online_path` (the adapter runs it off the
21 * event loop, on the cache-fill path), returning 0 on success.
22 *
23 * Contract (all return 0 = success unless noted; called off the event loop):
24 * int brix_frm_hsm_exists (const char *key);
25 * 0 = key is known to the MSS (on tape / recallable); non-0 = absent.
26 * int brix_frm_hsm_recall (const char *key, const char *online_path);
27 * materialise `key` into `online_path` (parents pre-created); 0 = online.
28 * int brix_frm_hsm_migrate(const char *key, const char *online_path);
29 * copy the online-buffer object back to tape; 0 = migrated.
30 * int brix_frm_hsm_purge (const char *key); [OPTIONAL — may be absent]
