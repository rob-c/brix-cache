4/*
5 * admin_unix.h — the verb-agnostic unix-domain admin transport.
6 *
7 * WHAT: a per-worker unix-socket line server. A caller supplies a table of
8 * verbs and an opaque `ud`; this TU owns everything else — the socket,
9 * the per-worker path, the accept/read/write event handlers, the
10 * one-command-per-line framing, and the reply arena.
11 *
12 * WHY: §1.16's ROOT admin socket (`brix_admin_socket`) and §2.x's CMS admin
13 * socket (`brix_cms_admin_socket`) are the SAME transport carrying
14 * different verbs. The transport half — accept, wire the I/O vtable a
15 * bare ngx_get_connection() leaves NULL, accumulate to a newline, refuse
16 * an oversized line, flush a reply with NGX_AGAIN handling, name the
17 * per-worker path — is ~200 lines of event-loop detail that must not be
18 * written twice; a second copy is a second place for a partial-write or
19 * a missing-vtable bug to live. CLAUDE.md: never reimplement HELPERS.
20 *
21 * HOW: `brix_admin_unix_listen()` creates worker 0's socket at <path> and
22 * worker n's at "<path>.<n>", then dispatches each complete line against
23 * the verb table by exact-name (bare verbs) or name-plus-space (verbs
24 * taking operands). A handler receives ONLY its operand text, so no verb
25 * re-derives the offset of its own arguments. Unknown lines answer
26 * "err unknown-command\n" here, uniformly, rather than in each table.
27 *
28 * SECURITY: the socket is chmod 0600 (owner-only) and carries NO in-band auth
29 * — filesystem permission on the path IS the privilege boundary, exactly
30 * like stock's adminpath. Every verb table inherits that model, so a verb
31 * added to any table is reachable by exactly the users who can open the
32 * path and no others. A caller must not place a socket where that is not
33 * the boundary it wants.
34 */
