int brix_plat_fuse_opt_supported ( const char * opt)

1 when the libfuse mount option opt (one comma-separated element, e.g.

"auto_unmount" or "attr_timeout=0") exists on this host's libfuse; 0 when it is a Linux-only spelling the host's library would reject outright (macFUSE: "auto_unmount", which it performs unconditionally anyway). Mount apps drop unsupported elements before fuse_main() so one option string serves every host. Pure; exact-match on the option name.

◆ brix_plat_umount_expire()

int brix_plat_umount_expire ( const char * path)

Two-phase idle expiry of a mount (Linux umount2(MNT_EXPIRE), root only): 0 = unmounted now, -1/EAGAIN = marked and left for the next call, -1/EBUSY = in use, -1/EPERM = not permitted.

Darwin has no expiry and always answers EPERM, so callers disable the feature the same way an unprivileged Linux run does.
