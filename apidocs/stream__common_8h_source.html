1/* stream_common.h — unified brix storage/x509 grammar (STREAM plane)
2 *
3 * WHAT: one stream module owns the bare storage + GSI-trust grammar
4 * (brix_export, brix_allow_write, brix_verify_write, brix_storage_backend,
5 * brix_storage_credential, and — stage 2 — the x509 trust family) so
6 * root:// and the gridftp gateway share a single directive surface.
7 * WHY: nginx's ngx_conf_handler is first-module-wins on directive names, so a
8 * shared stream name must be registered by exactly one stream module.
9 * Before phase-101 W3, gridftp could not use the bare names (they routed
10 * to the root module) and so grew 11 prefixed brix_gridftp_* twins.
11 * HOW: values land in this module's ngx_http_brix_shared_conf_t (the
12 * plane-neutral preamble); the root and gridftp modules copy the values
13 * into their own embedded preamble via brix_stream_common_adopt() at
14 * merge_srv_conf time. The adopt folds the CURRENT server's srv conf
15 * (fields set at parse time), so it is correct regardless of this
16 * module's merge order relative to root/gridftp — which matters because
17 * the module is emitted AFTER ngx_stream_brix_module to preserve the
18 * ngx_stream_brix_module.so name (see ./config).
19 */
