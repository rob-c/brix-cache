1/*
2 * metrics/metrics_oci.h
3 *
4 * Per-process OCI distribution metrics (phase-104 D3.1): the fixed label
5 * vocabularies for the mirror and registry surfaces plus the aggregate struct
6 * embedded in the per-server metrics block. Split out of metrics.h so each
7 * observability domain owns a focused header (the cluster is referenced only
8 * by ngx_brix_metrics_t via the embedded `oci` member).
9 *
10 * INVARIANT #8 by construction: every label here is an enum index into a
11 * compile-time name table. Repository names, tags and digests arrive FROM THE
12 * WIRE and are unbounded, so none of them is ever a label value — the question
13 * "which image is hot?" belongs to the access log, not to the scrape.
14 */

63/* Upstream failure buckets. Bucketed, not raw status codes: 401/403 separate

77/* Delegated-pull (D16) proof dispositions. `cached` is an SHM proof-cache

80 * unreachable upstream (502 — the gate fails CLOSED, never open). */
