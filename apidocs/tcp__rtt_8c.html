Kernel TCP statistics for the connected socket fd: smoothed round-trip time and its variation in MICROSECONDS, plus the retransmitted-segment count.

Linux reads TCP_INFO; Darwin reads TCP_CONNECTION_INFO, whose equivalents are in milliseconds and are converted here so callers see one unit on every host.

Returns
0 with the three outputs set, or -1 when the host cannot report them
