2 * brixautofs_ext_internal.h — private Phase-38 split contract for the CVMFS
3 * automount umbrella daemon, shared ONLY between brixautofs.c (core: the pure
4 * validator/table state machine plus the libfuse per-request handlers and the
5 * ops table) and brixautofs_ext.c (lifecycle: signals, child reaper, idle
6 * expiry, option parsing, mount-farm/config bring-up and the entry point).
7 *
8 * WHAT: the umbrella's process-global daemon state and the handful of core
9 * helpers/objects the lifecycle TU calls.
10 * WHY: not a public API — the pure core (compiled standalone with
11 * -DBRIXAUTOFS_UNIT) still lives in brixautofs.h. This header is guarded
12 * by the same BRIXAUTOFS_UNIT switch's absence: it pulls in libfuse and
13 * is included ONLY inside each TU's `#ifndef BRIXAUTOFS_UNIT` block, so a
14 * unit build never sees it. Behaviour is unchanged from the pre-split
15 * single file. See docs/refactor/phase-38-file-size-unix-modularity.md.
16 * HOW: every extern/prototype is DEFINED in brixautofs.c. The daemon is
17 * single-threaded per FUSE request with its own control/idle threads;
18 * g_af's concurrency is governed by tab's mutex as before.
19 */
