25 * ngx_http_brix_shared_conf_t — Common fields embedded at the top of every
26 * protocol location/server config struct (stream, WebDAV, S3).
27 *
28 * WHAT: A shared preamble that holds enable flags, root path, write permission,
29 * and thread pool name — fields present in all three protocol configs. Each
30 * protocol struct embeds this struct as its first member so offsetof() offsets
31 * into the protocol-specific tail remain valid after merge.
32 *
33 * WHY: Stream, WebDAV, and S3 each duplicate enable + root + allow_write in
34 * their own structs and their create/merge functions (~90 total ngx_conf_merge_*
35 * calls). Consolidating these shared fields into one struct reduces merge
36 * boilerplate to ~30 protocol-specific calls plus a single preamble merge.
37 *
38 * HOW: Protocol structs declare this as their first member (no padding needed
39 * because it starts with ngx_flag_t which aligns naturally). The create function
40 * sets all shared fields to NGX_CONF_UNSET; the merge function uses standard
41 * nginx merge macros on each field before calling protocol-specific merge logic.
42 */
