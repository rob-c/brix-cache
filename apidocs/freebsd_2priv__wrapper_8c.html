Irreversibly confine an already non-root, fixed-identity storage helper.

Caller must first seal inherited descriptors to stdio, channel, root and log. Restrict the export/channel/log descriptor rights and enter capability mode; never pretend that Linux credential capabilities exist. Returns 0 or -1.

pid_t brix_plat_broker_fork ( int * process_fd)

Create an owned child whose last process-descriptor close terminates it.

Returns fork's pid/zero, or -1 with errno. Unsupported hosts return ENOTSUP. The descriptor belongs only to the parent; no numeric-pid cleanup is needed.
