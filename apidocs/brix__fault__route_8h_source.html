1/*
2 * brix_fault_route.h — named routes: independent listener→upstream mappings (C2).
3 *
4 * The base proxy is one listener forwarding to one target pool. A route adds
5 * further named (listener-port → own target pool) mappings that run alongside it,
6 * each with its own connection/byte counters, while the global fault levers and
7 * toxics apply uniformly to every route. This lets one running proxy stand in
8 * for a small fabric of endpoints (`route add cache 6000 host:1094`) without a
9 * second process, and lets a test attribute traffic per endpoint.
10 *
11 * Split of concerns: this module owns the route TABLE (identity, target pool,
12 * counters) and the add/del/list control verb. The core owns the MECHANISM —
13 * binding a listener on the one vetted (loopback-gated) bind address and running
14 * the accept+relay engine — exposed through fp_route_ops so a dynamic route can
15 * never widen the control-plane bind gate: it reuses the same address, only the
16 * port differs.
17 */
