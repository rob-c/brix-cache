22/*
23 * adb_parse_ctx_t — everything the grammar helpers need to refuse a line.
24 *
25 * `defect` is the deferral seam. `brix_authdb` is a directive, but the ENGINE
26 * that consumes the file (`brix_authdb_engine native|xrdacc`) may not have been
27 * stated yet when the directive runs, and the same file is parsed by BOTH
28 * engines' parsers. Refusing an xrdacc-shaped file here would break every
29 * `brix_authdb_engine xrdacc` server, so a grammar defect is RECORDED (first
30 * one wins) and the merge — where the engine is final — turns it into an
31 * `nginx -t` failure for the native engine only. A NULL `defect` means the
32 * caller wants the defect raised immediately.
33 */
