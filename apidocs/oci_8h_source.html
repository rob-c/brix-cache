1/*
2 * oci.h — the OCI Distribution protocol plane: config, request ctx, seams.
3 *
4 * WHAT: the location config and per-request context for `src/protocols/oci/`,
5 * plus the handler entry point and the cross-file prototypes the module
6 * shares with its gate / serve / upstream-auth siblings.
7 * WHY: a container registry mirror is a *cache* with a URL grammar bolted on.
8 * Everything below the grammar — coalesced fills, ranged serving, digest
9 * verify-at-edge, TTL expiry on tag manifests, bounded stale-serve — is
10 * machinery the tree already runs for CVMFS. This header therefore
11 * declares only what is genuinely OCI: the upstream descriptor, the
12 * classified request, and the disposition the access log and the metric
13 * family both read (Appendix J.6 — one enum, never two stories).
14 * HOW: the shared preamble is the FIRST member of the loc conf (the tree-wide
15 * convention that lets brix_http_common_adopt / ngx_http_brix_shared_merge
16 * work on it), the surface flags default off, and nothing here allocates:
17 * a location without brix_oci_mirror / brix_oci_registry never grows a
18 * handler, so a non-OCI deployment is structurally untouched (J.2).
19 */

35/* The canonical route is "/v2/" + [namespace "/"] + name + "/" + terminal +
36 * "/" + reference. Name caps at 255, a tag at 128, a digest string at 72, and
37 * the namespace prefix is operator-supplied — 1 KiB clears every legal spelling
38 * with room to spare, and an over-long one is refused rather than truncated. */

157/* The floor on brix_oci_gc_interval, enforced at merge time and applied again

165 * short of "the operator will notice the space is still gone" — the same
166 * number `brixoci gc` defaults to, because it is the same question. */

245/* Read/write the sidecar beside the cached body at `body_path`. `size`/`mtime`
246 * are the body's own — a memo that does not describe the bytes it sits beside

248 * under the previous image's digest and media type, so a load whose record
249 * disagrees reports NGX_DECLINED (derive again) rather than NGX_OK. An mtime of
250 * 0 means "not available here" and validates on size alone, which is the whole

253 * write is staged+renamed. */

283/* The credential-scoped form of the dance (D16). `basic` is the exact
284 * "user:pass" to present to the token endpoint — NULL mints anonymously, and
285 * up->basic is deliberately NOT the fallback: the caller is speaking for a
286 * downstream principal, and "no credential" must never escalate into "the
287 * mirror's own credential". `cred` (32 raw bytes, or NULL) joins the SHM
288 * cache key so one principal's bearer can never satisfy another's request.
289 * 0 = token written (*expires_in > 0 on a fresh mint, -1 on a cache hit);
