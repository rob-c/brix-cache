14 * WHAT: Auth path selection via tpc_outbound_finish_login.
15 * - Parses login_body after session ID for "ztn" or "gsi"
16 * - Checks have_ztn_cred (delegated token or bearer file)
17 * - Checks have_cert (certificate + certificate_key set)
18 * - If want_ztn && have_ztn_cred: tries tpc_outbound_ztn first
19 * - On ordinary opportunistic-token failure: falls through to GSI if allowed
20 * - TLS-required and explicit token-mode failures are terminal
21 * - If want_gsi && have_cert: delegates to tpc_outbound_gsi
22 * - If neither succeeds: error + kXR_AuthFailed

24 * - Caller: thread.c (auth path dispatch after bootstrap)
25 *
26 * WHY: TPC pull outbound authentication needs to select between WLCG JWT (ztn) and GSI certreq auth paths based on what the server supports (advertised in login/authmore parameters) and what credentials are configured locally.
