5/*
6 * brix_configure_thread_pools — resolve thread-pool names to concrete pool
7 * objects for all XRootD-enabled stream server blocks.
8 *
9 * Called during postconfiguration. Iterates every stream server block and, if
10 * XRootD is enabled, looks up the configured pool name (or "default" if not
11 * explicitly set) in the nginx thread-pool registry.
12 *
13 * If the pool is not found and cache is enabled, the configuration fails with
14 * NGX_LOG_EMERG — cache I/O requires a thread pool. Otherwise, a NGX_LOG_NOTICE
15 * message is emitted and async I/O falls back to synchronous pread/pwrite.
16 *
17 * Returns NGX_OK on success, NGX_ERROR on missing required pool.
18 */

31 * Resolve each enabled server's thread-pool name to the concrete pool
