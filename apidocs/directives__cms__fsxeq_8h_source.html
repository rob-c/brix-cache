10 * POSIX leg for one or more forwarded namespace ops. Stock grammar:
11 *
12 * brix_cms_fsxeq <op>... <program> [<arg>...]
13 *
14 * where <op> is one or more of chmod mkdir mkpath mv rm rmdir trunc. The
15 * op's own arguments are APPENDED to the configured command line (stock
16 * XrdOucProg::Run semantics: mode/size first where the op has one, then the
17 * physical path, then the second path for mv). The op name is NOT

19 * disambiguates by baking a literal argument into the directive line.
20 *
21 * Repeatable; one op may name exactly one program (a second line naming an
22 * already-claimed op is a parse error, not a silent override). The program
