1/*
2 * space_group_conf.h — `brix_oss_space <group> <prefix> [quota=<size>|quota=-1]`
3 *
4 * WHAT: the per-server space-group table (phase-115 W3.3; the stock
5 * `oss.space` / `oss.cgroup` analog). A named group owns ONE
6 * export-relative path prefix and an optional byte quota. Longest-prefix
7 * lookup by logical path; lookup by name for the kXR_Qspace and
8 * kXR_open `oss.cgroup=` selectors.
9 *
10 * WHY: stock sites account and cap storage per space group (one per VO or
11 * activity) and clients select a group at create time with
12 * `oss.cgroup=`. Before W3.3 a server had one group name
13 * (brix_oss_cgroup) and one quota (brix_oss_quota): the report could name
14 * a group but never distinguish two, and a quota could only be
15 * export-wide.
16 *
17 * HOW: nginx-core types only (the table pointer lives in
18 * srv_conf_fields_auth.h). The setter validates the name with the same
19 * CGI-grammar rule brix_oss_cgroup uses (the name is emitted verbatim
20 * into the "&"-joined oss.* report), the prefix as an absolute,
21 * normalised, dot-segment-free path, and the quota as a non-negative size
22 * or the literal -1 (unlimited: accounting only). Duplicate names and
23 * duplicate prefixes fail the parse. The usage cache on each entry is
24 * per worker (copy-on-write after fork; never shared across workers).
25 */
