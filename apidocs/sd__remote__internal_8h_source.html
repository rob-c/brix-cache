40/* ---- xattr / setattr slots (defined in sd_remote_xattr.c) ------------------
41 * Metadata mutation over an s3:// object: setxattr/removexattr rewrite the
42 * user.<name> ↔ x-amz-meta-<name> surface, setattr patches the reserved advisory
43 * unix-attr blob. All three read the object's complete user-metadata set and
44 * rewrite it as a whole (an S3 metadata write REPLACES the entire set), so no
45 * co-existing attribute is dropped; they need the transport's raw-header
