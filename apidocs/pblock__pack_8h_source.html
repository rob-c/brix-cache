1/*
2 * pblock_pack.h — phase-88 W2: the packed small-blob arena.
3 *
4 * WHAT: A log-structured resting state for small immutable blobs: instead of a
5 * per-object dir + block file, a blob at/below pack_max whose staged
6 * commit kept it (not dedup-folded) is appended as ONE record into a
7 * shared segment file (<root>/pack/seg-<n>.dat) and its location kept in
8 * the catalog's `pack` table. One inode per ~64 MiB of small objects
9 * instead of two per object — the phase-87 G4 win, server-side.
10 *
11 * WHY: pblock's striped layout is a large-file design; a CVMFS-style cache
12 * store is dominated by small chunks where the per-object dir + block
13 * file COST inodes over the flat store. The client's packed store
14 * (shared/cache/cas_pack.c) proved the segment format but its runtime is
15 * single-process (in-memory hash + private journal) — nginx workers are
16 * many processes, so the arena reuses the RECORD FORMAT verbatim
17 * (shared/cache/cas_pack_format.h, records keyed by blob_id) while the
18 * cross-process index is the SQLite catalog and appends serialize under
19 * a pack/.lock flock.
20 *
21 * HOW: Packed is a metadata-boundary concept only — the hot byte path never
22 * sees it: a read open MATERIALISES the record into a sealed memfd (a
23 * real fd, so CAP_FD/SENDFILE hold and every byte op runs unchanged); a
24 * write-intent open materialises back to real block files first (packed
25 * blobs are single-block by admission, so the layouts are equivalent).
26 * Record crc32 is verified whenever a whole record is decoded (memfd
27 * open, materialise) — a damaged record is EIO, never wrong bytes.
28 * Deletion drops the row; a segment whose rows are all gone is unlinked
29 * (checked under the same flock appends hold, so an in-flight append —
30 * which inserts its row before unlocking — can never lose its segment).
31 * ngx-free (libc + sqlite3 + zlib crc32); BRIX_HAVE_SQLITE-gated.
32 *
33 * Requires: pblock_store.h (pblock_state_t), sd_pblock_catalog.h (pblock_meta)
34 * before inclusion.
35 */
