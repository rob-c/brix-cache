# Python packages the local test suite REQUIRES. Without these, collection
# fails — everything here is imported at module scope somewhere under tests/.
#
# Every entry carries a lower AND an upper bound. Lower bounds record the
# oldest release whose API this tree actually uses; upper bounds stop a new
# major from silently entering CI. Bumping a ceiling is a reviewed edit — that
# is the point. `tools/ci/check_python_deps.py` enforces both bounds, and that
# every third-party import is declared in one of these files.
#
#   requirements.txt           this file — required
#   requirements-optional.txt  feature-gated; tests importorskip them
#   requirements-dev.txt       external analysis tooling (CodeChecker)
#   k8s-tests/pytests/requirements.txt   cluster lab only
#
# System packages (ceph's python3-rados / python3-cephfs) are deliberately
# absent: they are not installable from PyPI and are pinned by the distro.
# See `SYSTEM_MODULES` in tools/ci/check_python_deps.py.
